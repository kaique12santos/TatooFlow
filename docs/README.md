# Documentação do Projeto TattooFlow

Esta pasta reúne a documentação acadêmica e especificações técnicas do projeto:

- `TAP.pdf`: Termo de Abertura do Projeto.
- `Estudo_de_Viabilidade.pdf`: Análise de viabilidade técnica, operacional e financeira.
- `Especificacao_de_Requisitos.pdf`: Especificação funcional (RFs) e não-funcional (RNFs).
- `Descritivo_Casos_de_Uso.pdf`: Detalhamento dos Casos de Uso.
- `diagramas/`: Diagramas de Caso de Uso, Classes, Arquitetura e DER.
