# Frontend TattooFlow (React Native + TypeScript + Expo)

## Estrutura do Projeto

- `src/api/`: Serviços Axios para consumo dos endpoints REST do backend.
- `src/components/`: Componentes reutilizáveis do Design System (Button, Input, Card, StatusBadge, EmptyState).
- `src/screens/`: Telas organizadas por módulo (auth, agenda, cliente, termo, midia, financeiro, estoque, relatorio).
- `src/navigation/`: Pilhas de navegação (AuthNavigator, TabNavigator, AppNavigator).
- `src/contexts/` & `src/hooks/`: Gestão de estado de autenticação.
- `src/theme/`: Tokens visuais (Cores, Tipografia, Espaçamento).
- `src/types/`: Interfaces TypeScript compartilhadas.

## Como Executar

```bash
npm install
npm start
```
